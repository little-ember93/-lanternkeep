LANTERNKEEP 1.5.1 — FULL GROVE

What is new
- Gratitude leaves now use count-responsive branch placement from 1 through 31 leaves
- Early months stay roomy; fuller months become progressively smaller and denser
- Dated tags remain visible while the trunk, path, and lantern details keep breathing room
- Monthly branches, on-device gratitude storage, and tree growth stages are unchanged
- Lanternkeep title art on the main page
- Gratitude Grove title art on the Grove page
- Decorative gratitude leaves with dated hanging tags
- Gentle leaf sway when the Grove loads
- A soft glow added around Reggie in the Keep scene

Upload steps
1. Keep using the same GitHub repository and Pages address so your private on-device data stays connected to the same site.
2. Open this package folder and select EVERY file inside it at once.
3. Upload all selected files to the repository root using Add file > Upload files.
4. Commit the changes and wait for GitHub Pages to publish.
5. Open Lanternkeep once in regular Safari while online, then fully close and reopen the Home Screen app.

Privacy
Tasks, gratitude text, settings, water, and daily progress remain in local browser storage on your device. They are not stored inside this upload package.
